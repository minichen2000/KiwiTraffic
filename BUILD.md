# Building KiwiTraffic

## Prerequisites

| Tool | Version | Notes |
| --- | --- | --- |
| Windows | 10 / 11, x64 | WPF is Windows-only |
| .NET SDK | 10.0.4xx | pinned by `global.json` |
| PowerShell | 7 (`pwsh`) | the build script requires PS 7 |
| Node.js | 18+ | **optional** — only wraps the build commands |

Windows PowerShell 5.1 will not work for `scripts/build.ps1`; use `pwsh`.

## Commands

```powershell
# Fast build for daily verification -> dist/fast/KiwiTraffic.exe
npm run build:exe

# Full quality gates + release build -> dist/release/KiwiTraffic.exe
npm run build:release

# Tests only
dotnet test

# Clean every bin/obj and the whole dist/ tree
npm run clean
```

The same thing without Node.js:

```powershell
pwsh -File scripts/build.ps1 -Configuration fast
pwsh -File scripts/build.ps1 -Configuration release
pwsh -File scripts/build.ps1 -Configuration fast -Clean
```

## What the two modes do

| | `fast` | `release` |
| --- | --- | --- |
| Restore | yes | yes |
| Build | via `publish` | solution build, **warnings as errors** |
| Tests | skipped | `dotnet test` on the whole solution |
| ReadyToRun | off | **on** (slower build, faster startup) |
| Output | `dist/fast/KiwiTraffic.exe` | `dist/release/KiwiTraffic.exe` |

Both publish the same thing otherwise: `win-x64`, self-contained, single-file.
`SelfContained`, `PublishSingleFile`, `RuntimeIdentifier` and
`IncludeNativeLibrariesForSelfExtract` are set in `src/KiwiTraffic.App/*.csproj`,
not on the command line, so no invocation can accidentally produce a
framework-dependent or multi-file artifact.

The script prints the artifact path, version, size and SHA-256 at the end.

## Deliverable policy

- The distributable is **one EXE**, no installer. MSI / MSIX / NSIS are never
  produced — do not add packaging configuration.
- "Single file" does **not** mean "nothing ever touches the disk": the .NET
  single-file host may extract native components, and settings/credentials are
  written to `%LOCALAPPDATA%\KiwiTraffic\`.
- WPF trimming and Native AOT are **not** enabled. They are unverified for this
  app and are known to break WPF's reflection-based paths. Do not turn them on
  to shrink the EXE without a full manual verification pass.

## Package lock files

Each project commits a `packages.lock.json` (generated by
`RestorePackagesWithLockFile` in `Directory.Build.props`). After changing any
`PackageReference`, regenerate the lock file:

```powershell
dotnet restore --force-evaluate
```

and commit the updated `packages.lock.json` together with the project change.

## Version numbers

`Directory.Build.props` holds the single `<Version>` value. `scripts/build.ps1`
reads it (for the build report) and the release workflow refuses to run if the
pushed tag does not match it.

## Release process

Release is built in the cloud, never uploaded by hand:

1. Make sure `main` is pushed and CI-worthy.
2. Update `CHANGELOG.md` (move `Unreleased` entries under the new version, add
   the date) and bump `<Version>` in `Directory.Build.props` if not already done.
3. Commit, then tag and push:

   ```powershell
   git tag -a v0.1.0 -m "v0.1.0"
   git push github main
   git push github v0.1.0
   git push gitee main
   git push gitee v0.1.0
   ```

4. The tag push triggers `.github/workflows/release.yml` on `windows-latest`,
   which verifies the tag, runs `scripts/build.ps1 -Configuration release` and
   attaches `dist/release/KiwiTraffic.exe` to a GitHub Release with generated
   notes.

GitHub is the only release channel. Gitee receives code and tags only — no
Release pages there.

## Troubleshooting

- **`dotnet: command not found` / wrong SDK** — run `dotnet --list-sdks`. The
  SDK must satisfy `global.json`; install .NET 10 from
  <https://dotnet.microsoft.com/download/dotnet/10.0>.
- **NuGet timeouts** — check whether the machine needs a proxy. NuGet has no
  China mirror configured on purpose; verify `dotnet nuget list source` points
  at `https://api.nuget.org/v3/index.json` and that the proxy is reachable.
- **`RestoreLockedMode` failures** — you changed a `PackageReference` without
  regenerating the lock file; see above.
